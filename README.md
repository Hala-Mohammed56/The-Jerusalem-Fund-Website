# The-Jerusalem-Fund-Website

This project is a **Vue 3 + Vite** website built to represent **The Jerusalem Fund** — an independent, non-profit organization promoting **education, culture, and humanitarian support** for Palestine.  

---

## 🏗️ Project Overview  

The website showcases the foundation’s mission, upcoming events, blogs, and cultural initiatives. It’s designed to be **modern, responsive, and visually aligned** with the Fund’s branding.  

---

## ✅ Current Pages  

### 🏠 **Home Page**  
Fully developed with:
- Responsive top navigation & header  
- Hero section with background overlay  
- About & mission highlights  
- Featured articles & blogs  
- Upcoming events preview  
- What We Do section  
- Footer with contact and social links  

### 👥 **Who We Are**  
Includes:
- Mission & History sections with visuals  
- Board of Directors section  
- Integrated `Header` and `Footer` components  

### 📰 **Blog & Blog Details**  
- Dynamic blog grid (20 posts, 4×5 layout)  
- Single blog details page with image, title, and content  

### 🎭 **Events & Past Events**  
- Upcoming events displayed in a 3×3 grid layout  
- Past events page with 9 cards and “See All” button

## 🧰 Installation & Setup  

```bash
# Clone the repository
git clone https://github.com/HalaMohammed/The-Jerusalem-Fund.git

# Navigate into the project folder
cd The-Jerusalem-Fund

# Install dependencies
npm install

# Run the development server
npm run dev
```
